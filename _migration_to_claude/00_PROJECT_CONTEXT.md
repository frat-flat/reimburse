# 00_PROJECT_CONTEXT.md

## 1. プロジェクトの目的
本プロジェクト（アプリケーション名: **TaTekæTa** / タテカエタ）は、旅行・飲み会・合宿・イベント等における複数人の複雑な立替支出を、シンプルかつ公平に割り勘・精算し、精算完了後の領収書発行（インボイス対応・押印調整対応）までをワンストップで完結させるWebアプリケーションである。

---

## 2. 誰向けのシステムか（対象ユーザー）
- **イベント主催者・幹事**:
  - 複数メンバーの支出を集計し、最小送金回数アルゴリズムによる精算ルートの自動算出、参加者への精算依頼、領収書発行、入金確認を一括管理したいユーザー。
- **イベント参加者・クルー（Mate）**:
  - 自分の負担額や立替額、支払い先（PayPayリンクや銀行振込先口座）を分かりやすく確認し、スムーズに送金・受取確認を行いたいユーザー。
- **経費精算・領収書を必要とする参加者・法人/個人事業主**:
  - 精算後に宛名や但し書き、消費税率（10%/8%/非課税）、発行元情報（インボイス登録番号、電子印鑑）が記載された正式な領収書PDF/印刷物を発行・受取したいユーザー。

---

## 3. AIがこのプロジェクトで担当している範囲
- **フルスタック設計・実装**:
  - Next.js (App Router / React Server Components / Server Actions) によるフロントエンドおよびバックエンドロジックの実装。
  - Prisma ORM を用いた PostgreSQL（Supabase）データベース設計・マイグレーション・クエリ最適化。
  - 割り勘計算ロジック（均等割、割合指定、固定金額指定、比率指定、残金均等割）および最小取引回数精算アルゴリズムの実装。
  - 領収書プレビュー（印鑑ドラッグ配置、透過度スライダー、印刷CSS、PDF出力）機能の実装。
  - ユーザー間フレンド（Mate）機能、イベント共有権限制御（主催者、編集可能、全体閲覧、個人閲覧）の実装。
  - 通知システム（アプリ内ベル通知ドロップダウン、全文閲覧モーダル）および Resend 連携による登録メールアドレス宛て自動HTMLメール通知配信の実装。
  - モバイルUI/UX刷新（レスポンシブ最適化、PWA対応、ハンバーガードロワー、フローティング電卓/新規作成ボタン）。
  - パフォーマンスチューニング（DB接続プール拡張、React cache による認証メモ化、Promise.all によるクエリ並列化、楽観的UI更新）。

## 6. 重要な前提条件
- **技術スタック**: Next.js 16 (App Router / Turbopack), React 19, TypeScript 5, Tailwind CSS 4, Prisma 6, PostgreSQL (Supabase), Resend.
- **言語・UI基準**: UIテキスト、通知メッセージ、メール文面はすべて自然な日本語を基準とする。
- **セキュリティ・データ保全**:
  - パスワード等の認証情報やAPIキーなどのシークレット情報はコード内にハードコードせず、環境変数経由で扱う。
  - 既存のDBレコード（精算履歴・領収書データ等）との整合性を常に維持する。
